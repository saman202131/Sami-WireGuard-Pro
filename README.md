# Sami WireGuard PRO MAX — اتصال‌پذیر به ربات

## انتشار روی Render
1. محتوای ZIP را (نه خود ZIP) در ریشه مخزن GitHub قرار بده.
2. Build Command: `npm install`
3. Start Command: `npm start`
4. در Environment متغیر `ADMIN_PASSWORD` را با رمز قوی تنظیم کن.
5. سایت: `/`، پنل: `/admin`، سلامت: `/health`.

## راه‌اندازی اتصال ربات
1. در پنل ادمین، بخش «اتصال ربات ↔ سایت» را باز کن.
2. URL عمومی HTTPS، عنوان و username ربات را وارد و ذخیره کن.
3. «ساخت/تعویض کلید API» را بزن و ذخیره کن.
4. همین API key را در کد سمت سرور ربات به‌عنوان secret تنظیم کن. هرگز آن را در HTML یا پیام عمومی قرار نده.

### APIهای ربات
تمام مسیرهای زیر نیازمند هدر `X-API-Key: <API_KEY>` هستند:
- `GET /api/integration/catalog` دریافت محصولات و بسته‌ها
- `PUT /api/integration/catalog` جایگزینی فهرست محصولات/بسته‌ها
- `POST /api/integration/orders/{ORDER_ID}/status` تغییر وضعیت سفارش به `pending`, `approved`, `rejected`, `fulfilled`

نمونه تنظیم در ربات: `BASE_URL=https://your-app.onrender.com` و `API_KEY=...`. باید کد ربات برای خواندن/نوشتن این APIها نوشته یا تنظیم شود؛ چون فایل ربات در اختیار نیست، این ZIP به‌تنهایی ربات را از راه دور تغییر نمی‌دهد.

## وضعیت فعلی و محدودیت‌ها
- تست پنل بررسی می‌کند URL و کلید API ثبت شده‌اند؛ موفقیت آن به‌تنهایی اتصال ربات را اثبات نمی‌کند.
- پرداخت واقعی، احراز هویت Telegram WebApp، صدور خودکار WireGuard/Vitory/DNS و جایزه واقعی گردونه نیازمند اتصال سرویس‌های مربوط و پیاده‌سازی سمت سرور هستند.
- داده‌ها در `data.json` نگهداری می‌شوند؛ برای پایداری روی Render از Persistent Disk یا دیتابیس استفاده کن.
- قبل از استفاده تجاری، rate limit، دیتابیس پایدار و تست end-to-end اضافه شود.


## امکانات توسعه‌یافته فروشگاه
- بخش «چرا سامی؟» برای نمایش مزیت‌های قابل ویرایش
- سوالات پرتکرار (FAQ) قابل مدیریت از پنل ادمین
- بنر باشگاه مشتریان با لینک کانال قابل تنظیم
- کلید روشن/خاموش ثبت سفارش و پیام وضعیت فروشگاه
- حفظ مدیریت سرویس‌ها، بسته‌ها، سفارش‌ها، گردونه و اتصال API ربات

مواردی مانند پرداخت آنلاین، کیف پول واقعی، کد تخفیف قابل مصرف، تیکتینگ، تمدید خودکار، صدور کانفیگ، اعلان واقعی ربات و گزارش مالی دقیق به درگاه پرداخت، API تأمین‌کننده، احراز هویت و دیتابیس پایدار نیاز دارند و در این نسخه صرفاً با ظاهر یا تنظیمات نمایشی فعال نمی‌شوند.
