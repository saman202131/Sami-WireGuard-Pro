# Sami WireGuard PRO Mini App

مینی‌اپ فارسی RTL با طراحی موبایلی تیره، کارت‌های سرویس، آیکون‌های متحرک، جست‌وجو، ثبت درخواست سفارش، پنل مدیریت و ابزار تست پاسخ مقصدهای عمومی.

## اجرا
- Node.js نسخه 18 یا جدیدتر
- Build Command در Render: `npm install`
- Start Command: `npm start`
- در Render متغیر `ADMIN_PASSWORD` را با یک رمز قوی تنظیم کنید.
- متغیرهای اختیاری: `SUPPORT_USERNAME=saman_s87` و `CHANNEL_URL=https://t.me/SamiWireGuard`
- فروشگاه: `/` — پنل مدیریت: `/admin` — بررسی سلامت: `/health`

## تست
- `npm run check` بررسی نحوی فایل‌های JavaScript است.
- `npm test` پس از نصب وابستگی‌ها، سرور را موقتاً اجرا کرده و سلامت، صفحات، API تنظیمات، مسیر تست شبکه، ورود مدیر و ایجاد/نمایش سفارش را بررسی می‌کند.

## نکات مهم پیش از فروش واقعی
- دکمه‌های تست شبکه، زمان پاسخ از میزبانی Render به مقصدهای عمومی (Cloudflare، Google و Google DNS) را اندازه می‌گیرند. این **پینگ واقعی گوشی کاربر به سرور WireGuard/V2Ray یا پینگ داخل بازی نیست**. برای تست واقعی هر سرور باید آدرس endpointهای واقعی آن‌ها در اختیار باشد.
- ثبت سفارش فقط درخواست را ذخیره می‌کند؛ پرداخت واقعی، صدور خودکار کانفیگ/QR، لینک اشتراک و اتصال به پنل VPN در این نسخه پیاده‌سازی نشده است.
- بخش باشگاه/جایزه نمایشی است و جایزه واقعی صادر نمی‌کند.
- اطلاعات سفارش فعلاً در `data.json` ذخیره می‌شود. دیسک Render Free ممکن است پس از deploy یا restart پاک شود؛ برای استفاده تجاری، دیتابیس پایدار مانند PostgreSQL لازم است.
- برای استفاده به‌عنوان Telegram Mini App، آدرس HTTPS نهایی را در تنظیمات BotFather ثبت کنید. کتابخانه Telegram Web App به صورت اختیاری شناسایی می‌شود و وب‌سایت بدون آن نیز باز می‌شود.
- هرگز توکن ربات، رمز پنل VPN یا کلید API را داخل فایل‌های عمومی یا GitHub قرار ندهید.
