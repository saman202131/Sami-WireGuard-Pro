# Sami WireGuard PRO Mini App

مینی‌اپ فروشگاهی فارسی با طراحی موبایلی تیره/نئونی، سه سرویس آغازین WireGuard، V2Ray و DNS، صفحه گردونه، پنل مدیریت، افزودن سرویس و بسته، تغییر قیمت و وضعیت سفارش.

## محدوده این نسخه
- فروشگاه و پنل مدیریت قابل اجرا هستند؛ مدیر می‌تواند سرویس و بسته اضافه/حذف کند، قیمت/حجم/مدت را تغییر دهد و هر سرویس یا بسته را روشن/خاموش کند.
- سفارش‌ها به‌صورت درخواست در `data.json` ذخیره می‌شوند. این نسخه **به پنل‌های واقعی VPN وصل نشده**؛ پرداخت واقعی، صدور کانفیگ، لینک اشتراک، QR، موجودی و تمدید خودکار نیازمند API رسمی پنل‌هاست.
- گردونه در فروشگاه نمایش داده می‌شود و از مدیریت روشن/خاموش می‌شود؛ اعطای جایزه و چرخش واقعی عمداً تا پیاده‌سازی هویت امن تلگرام و ضدتقلب سمت سرور غیرفعال است.
- روی Render Free فایل‌محور بودن ذخیره‌سازی می‌تواند باعث از دست رفتن اطلاعات بعد از redeploy/restart شود؛ برای فروش واقعی PostgreSQL یا دیسک پایدار لازم است.

## GitHub + Render
1. ZIP را Extract کن. فایل‌های داخل پوشه پروژه را در ریشه یک GitHub Repository آپلود کن؛ پوشه اضافی نساز.
2. در Render: **New + → Web Service** و repository را انتخاب کن.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. در Environment متغیر `ADMIN_PASSWORD` را با یک رمز قوی تنظیم کن. `SUPPORT_USERNAME=saman_s87` و `CHANNEL_URL=https://t.me/SamiWireGuard` هم قابل تنظیم‌اند.
6. Deploy کن. فروشگاه در آدرس اصلی است؛ پنل مدیریت در `/admin`.

## اتصال به ربات تلگرام
آدرس HTTPS نهایی Render را در `@BotFather` → `/mybots` → انتخاب ربات → **Bot Settings / Configure Mini App** یا **Main Mini App** ثبت کن. سپس **Menu Button** را هم به همان آدرس وصل کن.

## تست محلی
Node.js 18+ لازم است. اجرا: `npm install`, سپس `npm run check`, سپس `npm start`. آدرس `/health` باید `{"ok":true,...}` برگرداند.

## امنیت
توکن ربات، API Key یا رمز پنل VPN را هرگز در فایل‌های عمومی یا GitHub قرار نده. قبل از فروش واقعی، اعتبارسنجی `initData` تلگرام، دیتابیس پایدار و API رسمی پنل‌های WireGuard/V2Ray/DNS را اضافه کن.
