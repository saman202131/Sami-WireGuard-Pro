# Sami WireGuard

نسخه یک‌تکه و mobile-first برای فروشگاه و پنل مدیریت Sami WireGuard.

## امکانات
- فروشگاه WireGuard با دسته‌بندی‌های WireGuard / DNS / V2Ray
- مدیریت فعال/خاموش کردن دسته‌ها
- مدیریت کامل محصول: افزودن، ویرایش، حذف، قیمت، موجودی، مدت، حجم، ویژه/فعال
- ثبت سفارش با رسید پرداخت
- مدیریت وضعیت سفارش و تحویل دستی لینک، کانفیگ، QR و یادداشت
- بازگشت موجودی سفارش ردشده
- تنظیمات نام سایت، کارت، نام صاحب کارت و شناسه‌های تلگرام
- مدیریت کد تخفیف و فلش‌سیل
- گردونه شانس با احتمال، موجودی، فعال/خاموش و کاهش موجودی جایزه پس از برد
- کیف پول، VIP، وفاداری، ماموریت و معرفی دوستان با ویرایش رکوردی
- سرورها، اعلان‌ها، تیکت‌ها، آمار، لاگ و بکاپ
- ظاهر حرفه‌ای تیره/نئونی و responsive

## اجرا
```bash
npm install
npm start
```

سپس:
- فروشگاه: `http://localhost:3000/`
- مدیریت: `http://localhost:3000/admin`

## ورود مدیریت
بهتر است این متغیرها را در Render یا محیط اجرا تنظیم کنید:
- `ADMIN_USER`
- `ADMIN_PASSWORD`
- `JWT_SECRET`

اگر تنظیم نشوند، مقادیر پیش‌فرض فقط برای تست محلی استفاده می‌شوند.

## تلگرام
شناسه‌های پشتیبانی، بات و کانال از پنل مدیریت قابل تغییرند. Bot Token نیز فقط در بک‌اند ذخیره می‌شود و در API مدیریت به‌صورت ماسک‌شده نمایش داده می‌شود.

> برای Telegram Premium Custom Emoji واقعی باید شناسه‌های Custom Emoji و اتصال واقعی Bot API اضافه شود؛ این نسخه از ایموجی‌های Unicode سازگار استفاده می‌کند.
