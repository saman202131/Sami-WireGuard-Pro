# Sami Premium — AI Motion Sticker Studio

یک سایت مستقل فارسی به‌همراه پنل مدیریت ربات تلگرام برای ساخت فایل‌های متحرک `.TGS` (Lottie فشرده‌شده). این پروژه از Sami WireGuard جداست.

## قابلیت‌های موجود در این نسخه
- ویرایشگر مرورگری عکس با ۸ فیلتر، متن، رنگ و جایگاه متن؛ خروجی PNG ثابت.
- ساخت تصویر از توضیح متنی از طریق OpenAI Images API و تبدیل آن به TGS.
- تبدیل عکس PNG/JPG/WEBP به TGS برداری واقعی؛ تصویر رستری داخل فایل نهایی embed نمی‌شود.
- ۵ حرکت کلی حلقه‌ای: pulse، wobble، bounce، spin و none.
- افکت‌های رنگی پایه در ربات: نئون، سیاه‌وسفید، گرم، سرد/یخی، طلایی، رنگین‌کمانی، سایه، vivid و soft؛ sparkle/shine در این نسخه فقط روشنایی/رنگ را تغییر می‌دهند و ذرات مستقل نمی‌سازند.
- حذف پس‌زمینه با API تصویر، در صورت تنظیم `OPENAI_API_KEY` و پشتیبانی endpoint/model انتخاب‌شده.
- ساخت پک ZIP شامل ۲ تا ۵ فایل TGS از ایده‌های متنی.
- ذخیره شخصیت‌های شخصی در شناسه مرورگر، شخصیت‌های عمومی مدیر، انتخاب سبک از پیش‌تنظیم‌شده.
- فروشگاه درخواست سفارش و پنل تأیید/رد دستی؛ **پرداخت آنلاین وصل نشده است**.
- اعتبار مصرفی برای تولید تصویر/TGS، شارژ اعتبار از پنل مدیریت، آمار پردازش‌ها و سفارش‌ها.
- اتصال توکن BotFather، اعتبارسنجی با Telegram `getMe`، ذخیره AES-256-GCM و راه‌اندازی worker پایتون.
- اعتبارسنجی فایل TGS پس از ساخت: gzip/Lottie JSON، ابعاد 512×512، 60 FPS، حداکثر 180 فریم و سقف 64 KiB.

## محدودیت‌های مهم (شفاف)
- حرکت فعلی روی کل طرح اعمال می‌شود؛ انیمیشن هوشمند مستقل چشم/دهان/دست، لیپ‌سینک و تبدیل ویدئو به حرکت شخصیت در این نسخه پیاده‌سازی نشده است.
- تبدیل عکس به مسیرهای برداری می‌تواند جزئیات را ساده کند؛ تصویر پیچیده ممکن است از سقف 64 KiB عبور کند و رد شود.
- فایل TGS با فایل ویدیواستیکر WebM فرق دارد. برای افزودن فایل به مجموعه، از ربات رسمی `@Stickers` و نوع Animated Sticker استفاده کن. پذیرش نهایی تلگرام با این پروژه به‌صورت زنده تأیید نشده است.
- اعتبار عمومی با `clientId` مرورگر شناسایی می‌شود؛ این روش احراز هویت قوی نیست و کاربر می‌تواند شناسه مرورگر را عوض کند. قبل از فروش عمومی/پرداختی، احراز هویت واقعی، محدودیت مصرف سمت سرور و ثبت پرداخت اضافه شود.
- سفارش‌های فروشگاه فقط ثبت و مدیریت می‌شوند؛ درگاه پرداخت و تحویل خودکار محصول وصل نیست.
- حذف پس‌زمینه و ساخت از متن به کلید API و هزینه سرویس تصویر وابسته‌اند. بدون `OPENAI_API_KEY`، ساخت از متن و حذف پس‌زمینه AI غیرفعال می‌شوند؛ تبدیل عکس به TGS همچنان قابل استفاده است.
- توکن ربات فقط روی سرور رمزگذاری می‌شود، اما `BOT_TOKEN_ENCRYPTION_KEY` باید ثابت بماند؛ تغییر آن می‌تواند مانع رمزگشایی توکن ذخیره‌شده شود.

## راه‌اندازی روی Render
1. همه محتویات این پوشه را در ریشه مخزن GitHub قرار بده؛ پوشه `stickerbot_worker` را حفظ کن.
2. در Render یک Web Service با Runtime برابر Docker بساز.
3. در Environment Variables، مقدار `ADMIN_PASSWORD` را به یک رمز قوی تغییر بده.
4. برای تولید تصویر و حذف پس‌زمینه، `OPENAI_API_KEY` را اضافه کن. `OPENAI_IMAGE_MODEL` به‌طور پیش‌فرض `gpt-image-1.5` است و در صورت نیاز می‌توانی آن را تغییر بدهی.
5. `BOT_TOKEN_ENCRYPTION_KEY` را تنظیم کن یا اجازه بده Render مقدار آن را از `render.yaml` تولید کند. پس از ذخیره توکن، این کلید را تغییر نده.
6. برای نگه‌داری توکن، اعتبارها و سفارش‌ها بین استقرارها، دیسک پایدار در مسیر `/var/data` لازم است. پیکربندی فعلی Render از دیسک پایدار و پلن سازگار استفاده می‌کند که ممکن است هزینه داشته باشد.
7. بعد از Deploy، `/admin` را باز کن، رمز مدیریت را وارد کن و توکن ربات را ثبت کن.
8. در تلگرام `/start` را بزن. برای ساخت از متن، ایده را پیام بده؛ برای عکس، دکمه «ساخت TGS از عکس» را بزن و تصویر را ارسال کن.

## اجرای محلی
- Node.js 20+
- Python 3.10+
- FFmpeg نصب باشد (موردنیاز بخش‌های قبلی پردازش رسانه)

```bash
npm install
python3 -m pip install -r stickerbot_worker/requirements.txt
cp .env.example .env
# ADMIN_PASSWORD و BOT_TOKEN_ENCRYPTION_KEY را تنظیم کن؛ برای قابلیت AI، OPENAI_API_KEY را هم اضافه کن.
npm start
```

## تست‌ها
```bash
npm run check
PYTHONPATH=stickerbot_worker python3 -m unittest discover -s stickerbot_worker/tests -v
```

تست‌های خودکار، کدها و ساختار TGS را در محیط محلی بررسی می‌کنند؛ اتصال زنده Telegram/OpenAI و استقرار واقعی Render باید با کلیدهای خودت آزمایش شود. توکن و API key را داخل GitHub عمومی یا پیام چت قرار نده. یک توکن را هم‌زمان در Render و Termux اجرا نکن؛ هر دو از long polling استفاده می‌کنند.
