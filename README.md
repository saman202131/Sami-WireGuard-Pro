# Sami WireGuard

Run with Node.js 20+:

1. Copy `.env.example` to `.env`.
2. Set `JWT_SECRET` and `ADMIN_PASSWORD`.
3. Run `npm install`.
4. Run `npm start`.

Store: http://localhost:3000/
Dashboard: http://localhost:3000/dashboard
Admin: http://localhost:3000/admin

The admin panel controls products, orders, payment settings, Telegram settings, coupons, flash sale, wheel, tickets, notifications, analytics and backups.
