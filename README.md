# Sami WireGuard — Ultimate Upgrade

این نسخه بر پایه `SAMI-WIREGUARD-FINAL.zip` قبلی ساخته شده و ساختار/ظاهر قبلی را حفظ می‌کند.

## قابلیت‌های اضافه‌شده
- ثبت‌نام با Telegram ID + انتخاب رمز عبور
- ورود با Telegram ID + رمز عبور
- خرید ۱ تا ۱۰ عدد
- نام سفارشی جداگانه برای هر سرویس
- پرداخت کارت‌به‌کارت با رسید
- درگاه آنلاین خاموش و قابل فعال‌سازی از مدیریت
- تأیید/رد پرداخت از پنل
- گردونه فقط بعد از تأیید پرداخت؛ هر واحد خرید = یک چرخش
- ربات مدیریت خصوصی جدا از ربات فروش
- اعلان فوری سفارش به ربات مدیریت
- تأیید/رد سفارش از ربات مدیریت
- تحویل لینک، QR، فایل `.conf` و نام سرویس
- مدیریت تنظیمات پرداخت و اطلاعات تلگرام
- ضدتقلب پایه، محدودیت ورود و لاگ فعالیت

## دو ربات
1. `TELEGRAM_BOT_TOKEN` = ربات فروش فعلی. این ربات جایگزین نمی‌شود.
2. `ADMIN_BOT_TOKEN` = ربات جدید و خصوصی مدیریت.

برای ربات مدیریت، `ADMIN_TELEGRAM_IDS` را با Telegram ID مدیر/مدیران تنظیم کنید.

## اجرا
```bash
npm install
npm start
```

روی Render، متغیرهای `.env.example` را در Environment تنظیم کنید.

## نکته Production
ذخیره‌سازی JSON روی دیسک برای Render پایدار نیست؛ برای Production واقعی باید Storage/DB پایدار متصل شود. همچنین HTTPS، secrets امن و محدودیت دسترسی ربات مدیریت باید تنظیم شوند.
