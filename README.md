# قالب فروشگاه آنلاین قابل تنظیم

مینی‌اپ فارسی/RTL و پنل مدیریت Node.js/Express برای فروشگاه آنلاین.

## اجرای محلی
- Node.js 18 یا جدیدتر
- `npm install`
- متغیرهای `.env.example` را در محیط تنظیم کن (فایل `.env` را به GitHub نفرست)
- `npm start`
- سایت: `http://localhost:10000/`، مدیریت: `http://localhost:10000/admin`، سلامت: `http://localhost:10000/health`

## استقرار Render
برای تنظیم دقیق، `RENDER_DEPLOY_FA.md` را بخوان. فایل `render.yaml` یک Web Service با فضای پایدار ۱ گیگابایتی تعریف می‌کند؛ این گزینه ممکن است هزینه داشته باشد. قبل از تأیید ساخت منابع، هزینه‌ها و پلن جاری Render را بررسی کن.

## جداسازی سایت از همگام‌سازی ربات
این نسخه عمداً پنل تنظیم اتصال ربات و API همگام‌سازی سایت را ندارد. برای ورود امن Mini App، در صورت استفاده از تلگرام، `TELEGRAM_BOT_TOKEN` فقط برای اعتبارسنجی `initData` لازم است.

## وضعیت عملیاتی
- ثبت سفارش، بررسی دستی رسید و مدیریت پایه از طریق پنل وجود دارد.
- API کلیدمحور برای خواندن کاتالوگ، ساخت سفارش رباتی و به‌روزرسانی وضعیت وجود دارد.
- سفارش رباتی از `externalOrderId`/`Idempotency-Key` برای جلوگیری از ثبت تکراری استفاده می‌کند.
- ورود مدیریت دارای محدودیت تلاش ناموفق در حافظه هر فرایند است؛ برای مقیاس چند نمونه‌ای باید rate limit مشترک و نشست پایدار افزوده شود.
- ذخیره‌سازی فعلی JSON است و برای استفاده واقعی فقط با فضای پایدار مناسب است؛ برای رشد و تراکنش‌های مالی باید PostgreSQL و مهاجرت تراکنشی انجام شود.
- بازپرداخت فقط درخواست را ثبت می‌کند و پول جابه‌جا نمی‌کند.
- صف تحویل صرفاً وضعیت کار را ثبت می‌کند؛ worker و API واقعی تأمین‌کننده هنوز لازم‌اند.
- پرداخت آنلاین، تحویل خودکار کانفیگ، موجودی واقعی، تمدید خودکار و اتصال کامل ربات بدون اطلاعات و API خارجی فعال نیستند.
- گردونه شانس به‌صورت پیش‌فرض خاموش است.

## بررسی کد
`npm run check` فقط بررسی استاتیک/نحو است؛ جای تست زنده پرداخت، تلگرام، تأمین‌کننده و Render را نمی‌گیرد.

## فهرست جامع قابلیت‌ها
تمام ایده‌ها و نیازمندی‌های مطرح‌شده برای نسخه‌های آینده در فایل `FEATURE_BACKLOG_FA.md` ثبت شده‌اند. ثبت در فهرست به معنی پیاده‌سازی نیست؛ وضعیت اجرایی و وابستگی‌های خارجی در `FEATURE_MATRIX_FA.md` توضیح داده شده است.

## تنظیم هویت برند و اتصال
راهنمای کوتاه تنظیم نام، لوگو، ربات، کانال و پشتیبانی: `WHITE_LABEL_SETUP_FA.md`.

- نام نمایشی فروشگاه در پنل مدیریت قابل ویرایش است. مقدار پیش‌فرض: `⚡ فروشگاه آنلاین | 🎮 سرویس گیمینگ`.
- ربات: `نام کاربری ربات خودتان`، کانال: `لینک کانال خودتان`، پشتیبانی: `یوزرنیم پشتیبانی خودتان`.
- آدرس پیش‌فرض Mini App: `آدرس دامنه خودتان`.
- همه ایده‌های مطرح‌شده در `FEATURE_BACKLOG_FA.md` ثبت شده‌اند؛ چک‌باکس‌ها و وضعیت سند عمداً نشان می‌دهند که ثبت ایده به معنی پیاده‌سازی آن نیست. پرداخت زنده و تحویل خودکار کانفیگ به کلیدها و API واقعی ارائه‌دهنده نیاز دارد.
- در پنل مدیریت بخش «مرکز قابلیت‌های PRO MAX» وضعیت قابلیت‌های موجود و موارد نیازمند توسعه/اتصال خارجی را توضیح می‌دهد.

### نمای خرید Mini App
در نسخه به‌روزشده، صفحه کاربر با CTA خرید، جست‌وجوی سرویس/بسته، علاقه‌مندی‌ها، مقایسه حداکثر سه سرویس و تب وضعیت پایه تکمیل شده است. علاقه‌مندی‌ها در مرورگر همان دستگاه ذخیره می‌شوند. تب وضعیت، پاسخ API و تنظیم فروشگاه را نشان می‌دهد و به‌تنهایی اثبات سلامت تونل WireGuard نیست. فهرست کامل ۸۰ ایده UX در `FEATURE_BACKLOG_FA.md` است؛ موارد وابسته به درگاه، ربات یا سرور باید جداگانه پیاده‌سازی و در محیط واقعی آزمایش شوند.

### تجربه پرداخت و گردونه فروشگاه
- صفحه پلن‌ها، خلاصه سفارش و پرداخت با هویت گرافیکی مشکی/بنفش نئونی به‌روزرسانی شده است.
- صفحه پرداخت دارای کارت بانکی گرافیکی، کپی شماره کارت/مبلغ/شناسه سفارش، پیش‌نمایش رسید و نمایش وضعیت ارسال است.
- گردونه مشتری ظاهر اختصاصی باشگاه مشتریان دارد؛ نتیجه از API سرور گرفته می‌شود.
- پیش از استفاده، در پنل مدیریت بخش پرداخت، شماره کارت، نام صاحب حساب و نام بانک واقعی را وارد کنید. مقادیر خالی عمداً با اطلاعات ساختگی پر نشده‌اند.
- این تغییرات به‌معنی فعال شدن درگاه پرداخت آنلاین یا تحویل خودکار کانفیگ نیست؛ رسید کارت‌به‌کارت همچنان باید توسط مدیر بررسی شود.


### پنل کاربری شناسه کاربری — نسخه تکمیلی
- کارت عضویت شناسه کاربری با نام/شناسه تلگرام و سطح باشگاه.
- داشبورد سفارش‌ها، تعداد سفارش، امتیاز و موجودی کیف پول بر پایه API پروفایل (فقط داخل Telegram Mini App و پس از اعتبارسنجی initData).
- دسترسی سریع به تاریخچه سفارش، سرویس‌های تأییدشده، کیف پول/امتیاز، کد دعوت، ثبت و مشاهده تیکت و تنظیمات.
- تنظیمات تم روشن/تیره و کاهش افکت‌ها در مرورگر ذخیره می‌شوند؛ تنظیمات اعلان فعلاً ترجیح محلی هستند و ارسال اعلان را خاموش/روشن نمی‌کنند.
- تاریخچه سفارش از API موجود خوانده می‌شود؛ نمایش کانفیگ واقعی، تاریخ انقضا، مصرف حجم، ریزتراکنش کیف پول و اعلان push/تلگرام به API/داده‌های عملیاتی تکمیلی نیاز دارند.
- ایجاد تیکت از Mini App اکنون نیازمند اعتبارسنجی هویت تلگرام است.


## رسید، بررسی مدیر و شانس گردونه
- پس از بارگذاری رسید، سفارش با وضعیت `receipt_submitted` ذخیره می‌شود و اگر `ADMIN_TELEGRAM_CHAT_ID` تنظیم شده باشد، پیام رسید جدید به آن چت تلگرام ارسال می‌شود.
- در پنل مدیریت > سفارش‌ها، مدیر می‌تواند رسید را تأیید، لغو یا درباره آن اخطار ثبت کند. برای لغو/اخطار توضیح اجباری است؛ برای تأیید/تحویل امکان وارد کردن لینک اشتراک دستی وجود دارد.
- برای اعلان در تلگرام، `TELEGRAM_BOT_TOKEN` و `ADMIN_TELEGRAM_CHAT_ID` را در متغیرهای محیطی Render تنظیم کنید. مدیر باید قبلاً ربات را Start کرده باشد تا ربات بتواند پیام بدهد.
- تعداد شانس گردونه هر پلن در پنل مدیریت > سرویس‌ها و بسته‌ها قابل تنظیم است؛ شانس پس از تأیید پرداخت به سفارش اضافه می‌شود. گردونه فقط در Mini App تلگرام با هویت معتبر کار می‌کند.
- اخطار در این نسخه ثبت و به کاربر اعلام می‌شود؛ مسدودسازی خودکار کاربر به سامانه احراز هویت/ربات و سیاست مسدودسازی تکمیلی نیاز دارد.
- لینک اشتراک دستی با HTTPS به کاربر ارسال می‌شود. تحویل خودکار واقعی فقط در صورت اتصال provider/API سرویس فعال است.


## قابلیت‌های اضافه‌شده در نسخه گردونه و باشگاه مشتریان
- انیمیشن چرخش گردونه و ذخیره تاریخچه جایزه‌ها برای هر کاربر تلگرام.
- کد تخفیف یک‌بارمصرف برای جایزه‌های درصدی گردونه و شانس اضافه برای جایزه «شانس دوباره».
- ورود کد تخفیف در فرایند سفارش؛ اعتبار و محاسبه تخفیف در سرور انجام می‌شود.
- کد دعوت قابل دریافت و ثبت؛ امتیاز اولیه دعوت و پاداش پس از اولین خرید تأییدشده معرف اعمال می‌شود.
- امتیاز وفاداری از سفارش تأییدشده و سطوح Bronze/Silver/Gold/VIP.
- امکان تنظیم زمان شروع و پایان کمپین گردونه از پنل مدیریت.
- یادآوری تلگرامی تمدید حدود سه روز قبل از پایان تقریبی مدت پلن؛ این زمان بر اساس مدت پلن از زمان تأیید محاسبه می‌شود و از تاریخ واقعی سمت تأمین‌کننده دریافت نشده است.
- داشبورد آمار فروش و وضعیت سفارش‌ها در پنل مدیریت موجود است.

محدودیت‌ها: این نسخه روی Render مستقر یا با تلگرام واقعی آزمایش نشده است. یادآوری تمدید نیازمند فعال‌بودن فرایند Node.js و پیکربندی ربات تلگرام است؛ برای یادآوری تضمین‌شده حتی هنگام خواب سرویس، زمان‌بند/worker پایدار یا سرویس خارجی لازم است. پاداش‌های دستی و حجم هدیه هنوز به تأمین‌کننده WireGuard وصل نیستند.

## به‌روزرسانی پنل و قابلیت‌های جدید
- پنل مدیریت اکنون بخش‌بندی شده است؛ با انتخاب هر تب فقط همان بخش (از جمله گردونه) نمایش داده می‌شود.
- مرکز گیمینگ، فهرست سرورها را بر اساس بازی دسته‌بندی می‌کند و زمان پاسخ endpoint سلامت HTTPS را پس از بررسی مدیر نمایش می‌دهد. این زمان پاسخ HTTP است، نه پینگ ICMP یا پینگ واقعی داخل بازی.
- تست سرعت داخل مینی‌اپ فقط سرعت دانلود از میزبان خود مینی‌اپ را تخمین می‌زند و سرعت خروجی VPN را تضمین نمی‌کند.
- خرید هدیه با شناسه عددی تلگرام گیرنده قابل ثبت است؛ پیام گیرنده پس از تأیید سفارش/تحویل ارسال می‌شود، مشروط به اینکه گیرنده ربات را Start کرده باشد.
- پرداخت از کیف پول سمت سرور موجودی را بررسی و کسر می‌کند، سفارش را تأیید می‌کند و دفتر تراکنش را ثبت می‌کند. شارژ خودکار بانکی هنوز وجود ندارد؛ مدیر باید موجودی را دستی تنظیم کند.
- در بخش سرویس‌های من امکان ثبت سفارش جدید برای همان پلن (تمدید دستی) اضافه شده است؛ تمدید خودکار یا تغییر تاریخ انقضای سرویس تا اتصال API تأمین‌کننده فعال نیست.
- سفارش‌های دارای الگوی تکراری/تخفیف غیرعادی برای بازبینی علامت‌گذاری می‌شوند؛ این یک هشدار کمکی است و تصمیم ضدتقلب خودکار یا مسدودسازی حساب نیست.
- قالب نقش‌های مدیر قابل تنظیم است، اما محدودسازی دسترسی واقعی بر اساس هر اپراتور تا زمان پیاده‌سازی ورود جداگانه اپراتورها فعال نیست.
- سبد خرید چندقلمی، درگاه پرداخت آنلاین، سرعت‌سنج اختصاصی VPN، تمدید خودکار واقعی و تحویل خودکار WireGuard همچنان به توسعه/زیرساخت جداگانه نیاز دارند؛ وجود گزینه یا تنظیم در پنل به‌تنهایی به معنی فعال بودن سرویس خارجی نیست.

## بهبود طراحی کاتالوگ گیمینگ
- صفحه سرویس‌ها از کارت‌های نئونی گیمینگ با عنوان فارسی و انگلیسی برای WireGuard، Vitory، DNS و DNS اختصاصی استفاده می‌کند.
- انتخاب هر کارت، پنجره انتخاب پلن همان سرویس را باز می‌کند؛ دکمه بازگشت به فهرست سرویس‌ها وجود دارد.
- بخش «DNS اختصاصی دست‌ساز | Custom DNS» در کاتالوگ تعریف شده است. مدیر می‌تواند در پنل سرویس‌ها از ابزار «آزمایشگاه DNS اختصاصی دست‌ساز» پلن با نام و قیمت دلخواه، حجم پیش‌فرض «نامحدود» و مدت پیش‌فرض ۳۰ روز بسازد و سپس «ذخیره همه سرویس‌ها» را بزند.
- ساخت این پلن صرفاً ثبت آیتم فروشگاهی است؛ ساخت/تحویل DNS واقعی یا اعمال محدودیت فنی حجم نیازمند اتصال به زیرساخت DNS است.


## قابلیت‌های افزوده‌شده در بسته نهایی تکمیلی
- باشگاه امتیاز مشتریان با مأموریت‌ها/دستاوردهای پایه و سطح مشتری براساس امتیاز.
- جایزه روزانه سمت سرور با محدودیت یک‌بار در روز و افزایش امتیاز.
- ساخت گیفت‌کارت توسط مدیر و مصرف امن با هویت تأییدشده تلگرام؛ اعتبار در کیف پول و دفتر تراکنش ثبت می‌شود.
- ثبت نظر فقط برای سفارش تأییدشده متعلق به همان کاربر؛ انتشار نظر نیازمند تأیید مدیر است.
- مرکز اعلان کاربر برای اعلان‌های ثبت‌شده در سامانه.

## محدودیت‌های باقیمانده (شفاف)
- پینگ داخل بازی، نقشه زنده سرورها، سرعت واقعی تونل VPN و تغییر اتصال WireGuard نیازمند سرور/ارائه‌دهنده و عامل پایش واقعی است؛ زمان پاسخ HTTPS جایگزین پینگ بازی نیست.
- درگاه بانکی، پرداخت خودکار، تحویل خودکار اشتراک، چت بلادرنگ، push notification مستقل، بازپرداخت واقعی و اتصال خودکار تاریخ انقضا به پنل ارائه‌دهنده بدون API/زیرساخت مربوط فعال نیستند.
- نقش‌های اپراتور در این نسخه قالب مجوز مدیریتی هستند؛ احراز هویت مستقل اپراتورها و enforcement کامل مجوزها باید پیش از استفاده تیمی تکمیل شود.
- نظرهای مشتری به‌صورت دستی از پنل مدیر تأیید می‌شوند؛ سامانه مأموریت‌ها و جایزه روزانه نسخه پایه است و ضدتقلب پیشرفته نیست.


## انتقال اطلاعات بین نسخه‌ها با کلید
در پنل مدیریت > پشتیبان‌گیری و تعمیرات، پیش از جابه‌جایی یا انتشار نسخه جدید روی «ساخت کلید انتقال» بزنید و کلید را کامل و امن ذخیره کنید. در نسخه جدید وارد همان بخش شوید، کلید را جای‌گذاری کنید و «انتقال اطلاعات به این نسخه» را بزنید. این فرایند سفارش‌ها، سوابق تراکنش کیف پول، موجودی کاربرانِ فاقد موجودی در مقصد، امتیازها، ارجاع‌ها، تیکت‌ها و تاریخچه گردونه را ادغام می‌کند و رکوردهای دارای شناسه تکراری را دوباره وارد نمی‌کند.

کلید انتقال رمزنگاری‌شده نیست؛ هرکس آن را داشته باشد می‌تواند اطلاعات حساس داخل آن را بخواند، پس آن را مثل فایل پشتیبان محرمانه نگه دارید. برای اطلاعات حجیم ممکن است اندازه کلید از محدودیت درخواست عبور کند؛ در آن صورت از فایل JSON پشتیبان و فضای ذخیره‌سازی پایدار استفاده کنید. این قابلیت اطلاعاتی را که در نسخه قبلی ذخیره نشده یا پس از پاک‌شدن دیتابیس از بین رفته‌اند بازیابی نمی‌کند.


## قالب‌های طراحی و کاتالوگ
از پنل مدیریت، بخش «🎨 طراحی سایت» می‌توان یکی از پنج قالب گیمینگ نئونی، ساده روشن، لوکس تیره، سایبرپانک یا امن و مینیمال را انتخاب کرد. همان‌جا می‌توان نمایش همه سرویس‌ها یا فقط WireGuard، DNS یا Vitory را تعیین کرد. این انتخاب‌ها فقط ظاهر و فهرست نمایش را تغییر می‌دهند؛ سرویس‌ها و پلن‌ها حذف نمی‌شوند.

## وضعیت سفارش و تحویل
در نسخه فعلی مسیر خرید شامل انتخاب سرویس، انتخاب بسته، بازبینی سفارش، نمایش اطلاعات پرداخت و ارسال رسید است. رسید باید در پنل مدیریت بررسی شود. این نسخه به‌تنهایی سرویس VPN را از سرور ایجاد یا تحویل نمی‌دهد؛ تحویل خودکار به API واقعی پنل/تأمین‌کننده و اتصال آن نیاز دارد.

## افزوده‌های نسخه ارتقای طراحی (گردونه، پروفایل و پرداخت)
- درصد احتمال و مقدار داخلی جایزه‌های گردونه فقط در API/پنل مدیریت باقی می‌ماند؛ پاسخ عمومی `/api/config` فقط عنوان جایزه‌ها را می‌دهد. نتیجه واقعی همچنان در سرور انتخاب می‌شود.
- برای گردونه ۵ قالب ظاهری وجود دارد: نئون گیمری، آرکید، مینیمال، طلایی VIP و سایبرپانک؛ مدیر می‌تواند نمونه جایزه متعادل، گیمری یا تخفیفی را بارگذاری و بعد تمام عنوان‌ها، درصدها، نوع و مقدار جایزه را تغییر دهد.
- مراحل انتخاب سرویس ۵ پوسته قابل انتخاب دارد: گیمری، مینیمال، شیشه‌ای، آرکید و VIP طلایی.
- پروفایل کاربر از داده‌های تأییدشده API برای نمایش نام/شناسه تلگرام، موجودی کیف پول، امتیاز و سفارش‌ها استفاده می‌کند. موجودی و سفارش‌های واقعی فقط پس از تأیید هویت Telegram WebApp نمایش داده می‌شوند.
- این نسخه با بررسی ایستای کد و اسکریپت‌ها چک شده؛ تست زنده Telegram/Render و اتصال درگاه یا پنل تحویل سرویس در محیط واقعی همچنان جداگانه لازم است.


## تغییر این نسخه: حذف اتصال همگام‌سازی ربات و سایت
در این نسخه تب تنظیم اتصال ربات، کلید API مشترک، مسیرهای `/api/integration/*` و API وضعیت اتصال از خود سایت حذف شده‌اند. توکن تلگرام (در صورت تنظیم) فقط برای اعتبارسنجی امن داده‌های Telegram Mini App و اعلان‌های اختیاری استفاده می‌شود؛ همگام‌سازی کاتالوگ یا سفارش بین ربات و سایت از پنل سایت قابل تنظیم نیست. پرداخت آنلاین و تحویل خودکار سرویس همچنان به API واقعی ارائه‌دهندگان نیاز دارند.


## امکانات افزوده این نسخه
- پنل مشتریان با جست‌وجو، مشاهده سفارش/موجودی/امتیاز و ابزار مسدودسازی/رفع مسدودی حساب.
- امکان تعیین تاریخ انقضا برای کد تخفیف از پنل مدیریت.
- حذف کامل تب اتصال ربات، تنظیمات کلید مشترک و مسیرهای API همگام‌سازی از سمت سایت.
- مسدودسازی روی عملیات حساس دارای هویت تأییدشده Telegram Mini App اعمال می‌شود؛ سفارش‌گذاری عمومی ناشناس هنوز نیازمند سیاست احراز هویت جداگانه است.
