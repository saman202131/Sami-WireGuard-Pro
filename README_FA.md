# ربات Sami Premium برای استیکرهای TGS

ربات پایتون دریافت عکس یا متن می‌کند و فایل `.TGS` واقعی (gzip-compressed Lottie JSON) می‌سازد.

## قابلیت‌ها
- متن به تصویر از طریق OpenAI Images API (نیازمند `OPENAI_API_KEY`).
- تصویر به مسیرهای برداری Lottie؛ ابعاد 512×512، 60 FPS، حداکثر 3 ثانیه و سقف 64 KiB.
- حرکت حلقه‌ای کلی: pulse، wobble، bounce، spin و none.
- افکت‌های رنگی پایه مثل neon، mono، warm، cool/ice، gold، rainbow، shadow، vivid و soft.
- حذف پس‌زمینه از طریق سرویس تصویر در صورت تنظیم API key.
- پنل سایت می‌تواند همین worker را اجرا کند؛ یا برای Termux به‌صورت مستقل اجرا شود.

## نصب مستقل در Termux
1. فایل ZIP را استخراج کن و وارد پوشه پروژه شو.
2. `bash run_termux.sh` را اجرا کن تا نیازمندی‌ها نصب شوند.
3. فایل `.env` را بساز/ویرایش کن و مقدار `BOT_TOKEN` را قرار بده.
4. برای تولید از متن و حذف پس‌زمینه، `OPENAI_API_KEY` را هم تنظیم کن.
5. `python bot.py` را اجرا کن و در تلگرام `/start` بزن.

## محدودیت‌ها
حرکت‌ها روی کل شکل اعمال می‌شوند، نه روی اعضای جداگانه شخصیت. افکت‌های shine/sparkles/stars فعلاً تغییر ساده روشنایی/رنگ هستند، نه ذرات مستقل. تصویرهای پیچیده برای رعایت سقف TGS ساده‌سازی می‌شوند یا ممکن است رد شوند. پذیرش فایل در تلگرام زنده در محیط ساخت آزمایش نشده است.
