تنظیمات فروشگاه

اتصال دوطرفه ربات و مینی‌اپ

این بخش کلید امن API و مسیرهای اتصال را آماده می‌کند. برای اتصال واقعی، کد ربات باید از API زیر استفاده کند؛ ثبت آدرس به‌تنهایی ربات را تغییر نمی‌دهد.

وضعیت اتصال هنوز بررسی نشده است.

اطلاعات لازم برای کد ربات

GET /api/integration/catalog
PUT /api/integration/catalog
POST /api/integration/orders/{ORDER_ID}/status
Header: X-Secret-Key: YOUR_SECRET_KEY

کلید API را فقط در کد سمت سرور ربات قرار بده، نه در پیام‌های عمومی یا کد HTML فروشگاه. دکمه «تست تنظیمات» آماده بودن URL و کلید را می‌سنجد؛ اتصال واقعی تا زمان استفاده ربات از این API جداگانه باید تأیید شود.

مدیریت سرویس‌ها و بسته‌ها

سرویس‌ها را فعال/خاموش کن، بسته اضافه کن و قیمت‌ها را تغییر بده. تغییر وضعیت در سایت اعمال می‌شود؛ قطع واقعی کاربر در پنل VPN نیازمند اتصال API است.

گردونه شانس

نمایش گردونه
روشن یا خاموش کردن بخش گردونه در فروشگاه

چرخش و اعطای جایزه واقعی تا تکمیل احراز هویت امن تلگرام و محدودیت ضدتقلب غیرفعال است.

امکانات پیشرفته فروشگاه

این تنظیمات در همان لحظه ذخیره و در صفحه مشتری نمایش داده می‌شوند. فهرست‌ها را به‌صورت JSON معتبر و با ساختار نمونه وارد کن.

وضعیت ثبت سفارش
در حالت خاموش، ثبت سفارش از سایت متوقف می‌شود.
نمایش باشگاه مشتریان
بنر کانال و پیام تبلیغاتی در فروشگاه مشتری

ایده‌های بیشتر: کد تخفیف واقعی، کیف پول، پرداخت آنلاین، تحویل خودکار، اشتراک و تمدید، ثبت تیکت، امتیاز وفاداری، اعلان تلگرام، گزارش فروش و اتصال پایدار دیتابیس نیازمند پیاده‌سازی سمت سرور/سرویس‌های واقعی هستند؛ صرفاً نمایش دکمه برای فعال شدن آن‌ها کافی نیست.

پرداخت کارت‌به‌کارت و رسید

شماره کارت در صفحه خرید مشتری نمایش داده می‌شود. بارگذاری رسید به‌معنی تأیید پرداخت نیست؛ مدیر باید تراکنش را بررسی کند.

سفارش‌ها

نسخه فعلی از فایل JSON استفاده می‌کند؛ روی Render ممکن است اطلاعات پس از redeploy پاک شود. برای فروش واقعی، دیتابیس پایدار لازم است.
