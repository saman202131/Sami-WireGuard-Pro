مرکز گیمینگ و پایش سرورها

بازی‌ها را انتخاب کن و endpoint سلامت HTTPS سرورها را ثبت کن. زمان پاسخ اینجا تأخیر HTTP است، نه پینگ ICMP یا تضمین پینگ داخل بازی. فقط آدرس سرورهایی را ثبت کن که مالک آن هستی یا اجازه پایش داری.

سروری ثبت نشده است.

تست سرعت دانلود واقعی نیازمند فایل تست و زیرساخت قابل‌اندازه‌گیری است؛ وضعیت سرور نیز فقط بر اساس پاسخ endpoint ثبت‌شده اعلام می‌شود. این ابزار عدد ساختگی تولید نمی‌کند.

🔑 کلید انتقال اطلاعات به نسخه جدید

قبل از جایگزینی فایل یا ساخت استقرار جدید، کلید بساز و کامل کپی کن. در نسخه جدید وارد پنل مدیریت شو و کلید را اینجا وارد کن تا سفارش‌ها، سوابق کیف پول، موجودی کاربران، امتیازها و داده‌های مرتبط منتقل شوند.

این کلید شامل داده‌های مشتریان و مالی است؛ آن را برای کسی نفرست. موجودی کاربری که از قبل در نسخه مقصد موجودی دارد بازنویسی نمی‌شود تا موجودی ناخواسته دوباره جمع نشود. کلید جایگزین بکاپ دائمی نیست؛ نسخه JSON را هم جداگانه نگه دار.

نکته مهم: کیف پول این نسخه دفترکل ساده مدیریتی است و پرداخت خودکار/برداشت بانکی انجام نمی‌دهد. مدیریت تأمین‌کننده اطلاعات اتصال را نگه می‌دارد؛ تحویل خودکار WireGuard/Vitory/DNS تا اتصال API مستند و واقعی هر تأمین‌کننده فعال نمی‌شود. برای ماندگاری اطلاعات روی Render، دیسک پایدار یا دیتابیس خارجی لازم است.

نسخه فعلی از فایل JSON استفاده می‌کند؛ روی Render ممکن است اطلاعات پس از redeploy پاک شود. برای فروش واقعی، دیتابیس پایدار لازم است.
