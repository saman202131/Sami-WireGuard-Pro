SAMI PREMIUM — نسخه Ultimate AI Motion Studio

این یک سایت مستقل است و ربطی به Sami WireGuard ندارد.

۱) همه محتویات پوشه پروژه را در ریشه مخزن GitHub آپلود کن. پوشه stickerbot_worker باید کامل بماند.
۲) در Render سرویس Web Service با Runtime برابر Docker بساز.
۳) متغیر ADMIN_PASSWORD را با یک رمز قوی تنظیم کن.
۴) برای ساخت تصویر از متن و حذف پس‌زمینه هوشمند، OPENAI_API_KEY را در Render اضافه کن. مصرف API ممکن است هزینه داشته باشد.
۵) BOT_TOKEN_ENCRYPTION_KEY را ثابت نگه دار. تغییر آن ممکن است دسترسی به توکن ذخیره‌شده را از بین ببرد.
۶) اگر می‌خواهی توکن، اعتبارها و سفارش‌ها پس از Deploy باقی بمانند، دیسک پایدار لازم است؛ پیکربندی فعلی از /var/data استفاده می‌کند.
۷) پس از Deploy، آدرس سایت را باز کن و به /admin برو. رمز مدیریت را وارد کن و توکن BotFather را ثبت کن.
۸) در تلگرام /start را بزن.

امکانات: ویرایشگر PNG، تولید از متن، تبدیل عکس به TGS برداری، حذف پس‌زمینه AI، ۵ حالت حرکت کلی، افکت‌های رنگی پایه، شخصیت‌های ذخیره‌شده، ساخت پک ZIP از ۲ تا ۵ ایده، اعتبار مصرفی، فروشگاه درخواست سفارش، مدیریت سفارش‌ها و مدیریت ربات.

محدودیت‌های واقعی:
- حرکت TGS روی کل شکل اعمال می‌شود؛ حرکت مستقل چشم/دهان/دست و lip-sync هنوز وجود ندارد.
- سفارش‌ها دستی هستند؛ درگاه پرداخت آنلاین متصل نیست.
- اعتبار بر اساس شناسه مرورگر است و برای محصول تجاری باید احراز هویت قوی‌تر اضافه شود.
- ساخت از متن و حذف پس‌زمینه نیازمند OPENAI_API_KEY هستند؛ بدون آن‌ها این دو قابلیت کار نمی‌کنند.
- TGS با WebM فرق دارد. پس از دانلود، برای ساخت مجموعه به @Stickers بده و Animated Stickers را انتخاب کن.
- تست خودکار انجام شده، اما اتصال زنده به تلگرام/OpenAI و Render از این محیط تأیید نشده است.

هیچ توکن یا کلید API را در GitHub عمومی نگذار. توکن را هم‌زمان در Render و Termux اجرا نکن.
