پروژه سایت Sami Premium + بخش اتصال ربات استیکرساز

فایل‌های سایت:
- index.html       صفحه اصلی سایت
- admin.html       پنل مدیریت
- server.js        سرور و API
- public/          فایل‌های عمومی سایت
- stickerbot_worker/ فایل‌های ربات پایتون

روش استفاده:
1) فایل ZIP را کامل استخراج کن.
2) تمام فایل‌ها و پوشه‌های داخل Sami_Premium_StickerBot_Site را در ریشه مخزن GitHub سایتت آپلود کن؛ خود ZIP را به‌جای فایل‌های پروژه آپلود نکن.
3) در Render، Build Command را روی npm install و Start Command را روی npm start قرار بده؛ یا تنظیمات render.yaml را بررسی کن.
4) برای اجرای ربات از پنل، سرور باید Python و FFmpeg و وابستگی‌های requirements.txt را داشته باشد. روی سرویس Render فعلی این مورد باید جداگانه پیکربندی و آزمایش شود.
5) از پنل مدیریت، بخش «ربات استیکرساز» را باز کن و توکن را وارد کن.

مهم: توکن واقعی را داخل ZIP یا GitHub قرار نده. این بسته به‌صورت ایستا از نظر ساختار ZIP بررسی شده، اما اجرای کامل روی Render/تلگرام در این محیط تأیید نشده است.
